🔥Midsummer Nine Sacred Woods Bonfire

◇Directions
1. Build the Midsummer bonfire using only the nine sacred Druid woods: apple, ash, birch, elm, hawthorn, hazel, oak, rowan, and thorn. 2. Allow the bonfire to burn fully. 3. Once completely extinguished, collect the ashes carefully. 4. The ashes carry concentrated magickal power and serve as the base for follow-up fertility workings.
◇Description
A Celtic and Druidic Midsummer bonfire built from nine sacred woods. The resulting ashes retain magickal power and are used in follow-up fertility workings.

☀️Midsummer

In Celtic regions of Europe, Midsummer bonfires may be built from carefully chosen sacred wood rather than herbs (as in the Mediterranean tradition). This version uses the nine sacred Druid woods.

The Nine Sacred Woods

Apple

The Working

  1. Build the Midsummer bonfire using only these nine woods.
  2. Once the fires have burned out, collect the ashes.

The ashes retain magickal power and can be used in follow-up fertility workings (see Midsummer Bonfire Ash Spells).
